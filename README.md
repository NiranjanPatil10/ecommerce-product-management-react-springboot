# E-Commerce Product Management System

A full stack web application for managing products in an e-commerce platform.  
This project is built using React for the frontend and Spring Boot for the backend with MySQL as the database.  
It demonstrates CRUD operations and REST API integration between frontend and backend.

## Tech Stack
Frontend: React.js, Axios, HTML, CSS  
Backend: Spring Boot, Spring Data JPA, Hibernate  
Database: MySQL  
Tools: Git, GitHub, Eclipse, VS Code, Postman

## Features
- Add new products
- View all products
- Update product details
- Delete products
- Category management
- RESTful API integration
- Admin dashboard for product management

## Running the Project

Backend:
Run the Spring Boot application in Eclipse  
Server Port: 8087

Frontend:
npm install  
npm start  

Frontend runs on: http://localhost:3000  
Backend runs on: http://localhost:8087
